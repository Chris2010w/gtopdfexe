# Gallery → PDF (Windows)

Desktop version of the iOS app. Downloads galleries (E-Hentai, ExHentai, nHentai, HentaiFox, HentaiEra, Hitomi, e621,
Rule34.xyz) into PDF/CBZ, and videos from any site yt-dlp supports (MP4, up to 2160p, audio merged with ffmpeg).

Run from source: `pip install -r requirements.txt` then `python app.py`.
The .exe is built by GitHub Actions (see .github/workflows/build-windows.yml): download the artifact `GalleryToPDF-Windows`,
unzip it, and run GalleryToPDF.exe.
